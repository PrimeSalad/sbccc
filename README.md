# Speak. Seek. Heal.

A static React + TypeScript mental-health awareness and support-seeking experience for
the Philippines. It includes a private browser-only check-in, trusted support links, a
WHO video, conversation starters, and an external Unchainly App Store link.

## Start locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run typecheck
npm run build
```

See [PROJECT_BRIEF.md](./PROJECT_BRIEF.md) for the research, safety notes, content plan,
architecture, sources, and launch checklist. See
[design-system/MASTER.md](./design-system/MASTER.md) for the visual and accessibility
system.
